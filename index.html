frc-maven

A Maven repository for a set of FRC robot libraries: plain files, served by GitHub Pages.

Add it to a Gradle build, limited to the libraries' group:

repositories {
    exclusiveContent {
        forRepository {
            maven { url = "https://mikegrundvig.github.io/frc-maven/" }
        }
        filter { includeGroup "com.michaelgrundvig.frc" }
    }
}
dependencies {
    implementation "com.michaelgrundvig.frc:frc-robot-runtime:2026.10.20"
}

Versions are release dates, one for all the libraries. They are pre-release: anything may change from one to the next, with no promise of compatibility. WPILib and the vendor libraries are not here; a robot program brings its own. The robot template is set up to use these already.
